# 🎯 LAB 10: Object Detection Using YOLO

เอกสารรายงานการทดลองและคู่มือปฏิบัติการเรื่อง **การตรวจจับวัตถุด้วยโมเดล YOLO (You Only Look Once)** สำหรับรายวิชาปัญญาประดิษฐ์และการประมวลผลภาพ

---

## 📌 1. วัตถุประสงค์การทดลอง (Objectives)
* ประยุกต์ใช้โมเดล YOLO ในการตรวจจับและจำแนกวัตถุจากชุดข้อมูล (Dataset)
* เปรียบเทียบประสิทธิภาพการตรวจจับวัตถุเมื่อปรับเปลี่ยนจำนวนรอบในการเทรน (Epochs) และการตั้งค่า Hyperparameters ต่างๆ
* ประเมินประสิทธิภาพของโมเดลด้วยตัววัดผลมาตรฐาน ได้แก่ Precision ($P$), Recall ($R$) และ mAP (Mean Average Precision)
* ทดสอบการตรวจจับวัตถุบนภาพถ่าย วิดีโอ หรือกล้อง real-time พร้อมแสดงผล Bounding Boxes, Class Labels และ Confidence Scores

        5.2 การวิเคราะห์ผลลัพธ์จากกราฟ (Loss & Performance Metrics)
ผลลัพธ์กราฟการเรียนรู้ถูกบันทึกไว้อัตโนมัติที่ runs/detect/lab_run_epoch50/results.png:

Training Loss & Validation Loss: ค่า Loss ทั้งในส่วนของ Box Loss, Class Loss และ DFL Loss มีแนวโน้มลดลงเรื่อยๆ เมื่อจำนวน Epochs เพิ่มขึ้น แสดงให้เห็นว่าโมเดลเกิดการเรียนรู้ที่ดีขึ้น[cite: 1]

Precision & Recall: เมื่อเทรนจำนวน 50 Epochs ค่า Precision และ Recall ปรับตัวสูงขึ้นเมื่อเทียบกับ 20 Epochs ทำให้โมเดลสามารถทายวัตถุได้แม่นยำและถูกต้องมากขึ้น[cite: 1]

5.3 ตัวอย่างผลลัพธ์การตรวจจับวัตถุ (Object Detection Output)
ภาพผลลัพธ์ที่ผ่านการประมวลผลด้วยโมเดล จะแสดงกรอบ Bounding Boxes, Class Labels และ Confidence Scores บนวัตถุอย่างชัดเจน[cite: 1] โดยไฟล์ผลลัพธ์จะอยู่ในโฟลเดอร์ runs/detect/predict/

6. สรุปและอภิปรายผลการทดลอง (Conclusion & Discussion)
ผลของจำนวน Epochs: การเพิ่มจำนวน Epochs จาก 20 เป็น 50 รอบ ช่วยให้โมเดลมีประสิทธิภาพการตรวจจับวัตถุสูงขึ้นอย่างเห็นได้ชัด โดยดูได้จากค่า mAP@0.5 ที่เพิ่มขึ้น[cite: 1]

การปรับปรุงในอนาคต: สามารถพัฒนาประสิทธิภาพเพิ่มเติมได้โดยการเพิ่มจำนวนรูปภาพใน Dataset, การทำ Data Augmentation หรือเลือกใช้สถาปัตยกรรมโมเดลที่มีขนาดใหญ่ขึ้น เช่น YOLOv8m หรือ YOLOv8l
